## 中文

本次发布将 PowerPoint 引用插件正式纳入 Zotero Linker 发布体系。

### 新增内容

- 新增 `zoterolinkerppt` PowerPoint / WPS Presentation 引用插件 `1.0.0`。
- 在幻灯片中调用 Zotero 文献选择窗口，支持单选和多选引用。
- 支持首次选择 CSL 引用样式、自动编号、参考文献页生成和刷新。
- Word 插件产品版本继续为 `1.0.3`，与 PowerPoint 插件独立维护。
- 安装包统一使用 `zoterolinkerword` 和 `zoterolinkerppt` 命名。

### 安装包

```text
zoterolinkerword-1.0.3.exe  # Word / WPS Writer
zoterolinkerppt-1.0.0.exe   # PowerPoint / WPS Presentation
```

## English

This release formally adds the PowerPoint citation add-in to the Zotero Linker release family.

### What's new

- Adds the `zoterolinkerppt` PowerPoint / WPS Presentation citation add-in at `1.0.0`.
- Opens Zotero's item picker from PowerPoint with single- and multi-select support.
- Supports CSL style selection on first use, automatic numbering, bibliography generation, and refresh.
- Keeps the Word product at `1.0.3`; Word and PowerPoint versions are maintained independently.
- Uses the `zoterolinkerword` and `zoterolinkerppt` package names.

### Installers

```text
zoterolinkerword-1.0.3.exe  # Word / WPS Writer
zoterolinkerppt-1.0.0.exe   # PowerPoint / WPS Presentation
```
