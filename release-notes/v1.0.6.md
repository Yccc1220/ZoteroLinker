## 中文

本次发布将 Word / WPS Writer 插件升级到 1.0.5，PowerPoint / WPS Presentation 插件保持 1.0.0。

### 补充功能

- 扩展正文引文识别，支持数字编号、APA、MLA、Chicago 作者—年份、叙述式和多文献组合引文。
- 新增手动“Link DOI”功能，可为参考文献中的 doi:、https://doi.org/ 和裸 DOI 建立超链接。
- DOI 链接会跳过已有超链接，避免重复创建。

### 问题修复

- 修复部分文档操作返回 HRESULT E_FAIL 时只显示无上下文错误的问题。
- 在受保护视图、只读文档或启用编辑保护时提供明确操作提示。
- 修复“Link Citations”自动把正文引文改为蓝色的问题。
- 修复“Remove Links”删除链接时改变原有颜色、下划线或字号的问题。
- 链接和移除操作现在保留正文引文及参考文献的原始格式；颜色和字号仅在用户于 Options 中明确点击应用时修改。

### 稳定性加强

- 加强 Word COM 字段、范围和超链接访问，降低无效对象导致的操作失败。
- 增加 APA、MLA、Chicago、Vancouver、DOI 解析及 Word 实际文档集成测试。
- DOI 功能使用独立工具栏图标，便于与正文引文链接功能区分。

### 安装包

~~~text
ZoteroLinkerWordSetup-1.0.5.exe  # Word / WPS Writer
ZoteroLinkerPptSetup-1.0.0.exe   # PowerPoint / WPS Presentation
~~~

## English

This release upgrades the Word / WPS Writer add-in to 1.0.5. The PowerPoint / WPS Presentation add-in remains at 1.0.0.

### Added

- Expands citation recognition for numeric, APA, MLA, Chicago author-date, narrative, and multi-source citations.
- Adds a manual “Link DOI” action for doi:, https://doi.org/, and bare DOI values in bibliographies.
- Skips DOI text that already contains a hyperlink to prevent duplicates.

### Fixed

- Replaces context-free HRESULT E_FAIL messages with actionable document-state errors.
- Detects Protected View, read-only documents, and editing protection before modifying a document.
- Stops “Link Citations” from automatically changing citation text to blue.
- Stops “Remove Links” from changing existing colors, underlines, or font sizes.
- Preserves citation and bibliography formatting during link and unlink operations; color and font size change only after an explicit action in Options.

### Improved

- Hardens Word COM field, range, and hyperlink access against invalid object states.
- Adds parser and Word integration coverage for APA, MLA, Chicago, Vancouver, and DOI workflows.
- Adds a dedicated ribbon icon for the DOI action.

### Installers

~~~text
ZoteroLinkerWordSetup-1.0.5.exe  # Word / WPS Writer
ZoteroLinkerPptSetup-1.0.0.exe   # PowerPoint / WPS Presentation
~~~
