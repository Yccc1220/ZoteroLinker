## 中文

本次发布修复了 WPS Writer 中工具栏看不到 Zotero Linker 的注册表配置问题。

### 修复内容

- 为当前用户写入 Word 加载项注册表项，确保 WPS 可以枚举到 `Zotero-linker`。
- 按 WPS 的 `AddinsWL` 规则写入白名单值，而不是错误地创建白名单子键。
- 同时写入 `Zotero-linker` 和 `Yccc1220.Zotero Linker` 两种 WPS 白名单值，兼容 WPS 实际枚举和安装器厂商/产品名规则。
- 清理脚本同步移除新版白名单值和旧版错误子键，减少升级后的残留影响。

## English

This release fixes the registry configuration that could prevent the Zotero Linker ribbon from appearing in WPS Writer.

### Fixes

- Registers the Word add-in under the current user so WPS can enumerate `Zotero-linker`.
- Writes WPS `AddinsWL` whitelist values instead of creating incorrect whitelist subkeys.
- Adds both `Zotero-linker` and `Yccc1220.Zotero Linker` whitelist values for compatibility with WPS enumeration and installer manufacturer/product naming.
- Updates cleanup logic to remove both the new whitelist values and the old incorrect subkeys during upgrade or uninstall.
